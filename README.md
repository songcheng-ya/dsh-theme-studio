# DSH 主题工作室

`dsh-theme-studio` 是 DeepSeek Harness（DSH）Web 界面的主题插件，在设置页提供“主题工作室”。它把壁纸、分区毛玻璃和自定义主题色集中到一个面板中，调整后即时预览并自动保存；总开关可以随时撤销插件效果，而不丢失已有设置。

## 壁纸来源

壁纸可以来自本地文件夹、远程图片链接或浏览器上传的图片。本地文件夹支持手动输入路径、浏览选择、登记多个目录以及按需扫描子目录；远程链接可以逐条添加和使用，由插件代理加载；上传图片则保存为插件自己的副本，上传完成即可使用。设置页会提示目录不存在、无法读取或扫描结果达到上限等情况。

## 选图与管理

本地文件夹和上传图片会显示在壁纸候选墙中，可以点选、重新扫描、分批加载更多，也可以用“换一张”从其他候选中随机挑选，或清空当前壁纸并恢复原背景。移除登记文件夹中的图片只影响本次会话的候选墙，不删除你的原图，重新扫描或刷新即可恢复；删除上传图片会删除插件保存的副本；删除远程链接会移除候选并清理对应的本地缓存，不影响远端原图。

## 壁纸表现

可调节壁纸模糊、亮度、饱和度、遮罩暗化、遮罩颜色、暗角和噪点。图片适配支持裁切铺满、完整显示、平铺与原始尺寸居中，并可设置居中、顶部、底部、左侧或右侧对齐。没有可用图片时，插件会尽量保留 DSH 原有背景，而不是只留下透明页面。

## 分区毛玻璃

侧边栏与顶边栏、输入框及提问/计划审批卡片、用户消息与附件气泡、AI 回复气泡、弹层菜单分别提供独立开关、不透明度、模糊度和遮罩颜色设置；还可统一调节描边强度与顶部高光。遮罩色既可跟随 DSH 明暗主题，也可选择浅/深色预设或自行取色。AI 回复气泡可单独关闭，恢复 DSH 原本的无气泡显示。

## 自定义主题色

主题色可以独立启用或关闭，提供 DeepSeek 蓝、远洋青、星云紫、樱花粉、琥珀金、松林绿、朱砂红和石墨灰八种预设，也可以通过 RGB 滑块或输入色值自定义。启用后，插件会为明暗界面派生相应色阶，影响按钮、开关、选中态、链接等品牌色元素。

## 自检与维护

“分区命中自检”会列出各分区样式选择器的命中数量，帮助判断 DSH 更新后某个毛玻璃效果是否失效。维护操作包括重新扫描目录、重选随机壁纸、一键关闭并复原、重置全部配置，以及仅清理上传副本和远程图片缓存；重置和清理操作需要再次确认。关闭插件会保留设置，重置配置才会恢复出厂值；单独清理本地缓存不会删除已登记目录中的原图。
